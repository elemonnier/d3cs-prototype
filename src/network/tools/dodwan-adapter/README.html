DoDWAN_Adapter: an adapter to run DoDWAN with LEPTON

  • DoDWAN is an opportunistic networking middleware system that allows mobile devices to exchange information using the publish/subscribe model.

  • LEPTON is a lightweight emulation platform for opportunistic networking.

This adapter makes it possible to run experiments with LEPTON, each emulated node being an instance of DoDWAN.

Please refer to the LEPTON documentation (in the how-tos) for details about how LEPTON can run with DoDWAN nodes.
